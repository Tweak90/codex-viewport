# Codex-Web 1.0.2

[Deutsch](https://github.com/Tweak90/codex-web/blob/main/docs/releases/v1.0.2.de.md)

The Settings gear now sits directly below the two allowance percentages in the narrow activity bar. The wide project sidebar no longer contains Settings or Usage limits entries. Compact icons keep both functions available in the mobile menu.

Uploads selected during chat creation now wait for that chat, preventing missing attachments. A controlled browser regression covers the delayed chat response.

All settings and quota details remain available. Compatibility: Codex 0.166.0 and Node.js 22. Image: `ghcr.io/tweak90/codex-web-ui:1.0.2` or `latest`.

Validation: 44 API/transport/publication tests, 25 browser tests, translation/documentation checks, Compose validation and Docker build. Publishing does not deploy the application. Downloads contain source, the `codex-vm-console:1.0.2` Docker archive and SHA-256 checksums.
